# 우주선 귀환 영역 주변 빈 공간과 바닥 생성 계획

작성: 2026-10-01. 상태: 초기 논의 기록. 마스터 생성기 구조와 선택적 바닥·독립적인 바닥 크기는 [확장 계획](2026-10-01-stage-generation-pipeline-plan.md)을 따른다.

## 1. 확정한 동작

- 필수 빈 공간의 원본은 씬에 놓인 우주선 `ReturnArea`의 `BoxCollider2D` 트리거다. 플레이어 스폰 좌표나 임의의 새 사각형으로 크기를 정하지 않는다.
- 트리거와 겹치는 타일 셀은 생성 직후 반드시 비어 있다. 트리거 바로 아래에는 트리거와 **동일한 셀 열 범위**로 평평한 암반 바닥이 반드시 존재한다. 스폰 좌표 바로 발밑에 바닥을 맞추는 작업은 이번 범위가 아니다.
- 두 필수 영역 밖으로 갈수록 공간/바닥 보장 효과가 감소하고 기존 다층 노이즈 지형이 점차 돌아온다. 경계 밖에서 노이즈 영향이 줄어드는 방향은 사용자가 의도한 규칙이 아니다.
- 바닥은 생성 직후에만 보장한다. 이후 기존 채굴로 부서질 수 있고, 파괴 불가 타일이나 자동 복구는 도입하지 않는다.
- 시작 공간이 다른 빈 공간과 이어지는지, 제트팩으로 탈출 가능한지, 생물이 안전하게 배치되는지는 이번 단계에서 판정하거나 시드를 재시도하지 않는다.

## 2. 현재 씬에서의 좌표 계약

`Stage_a_1`과 `EmptyStageTemplate`의 `SessionManager._playerSpawnPoint`는 우주선 루트 Transform을 참조한다. 두 씬의 우주선은 원점에 놓여 있다. 우주선 프리팹의 `ReturnArea`는 루트와 같은 위치에 있는 `BoxCollider2D` 트리거이며, 크기는 7×3, 오프셋은 0이다. `Stage_a_1`에서 월드 트리거 직사각형은 X `[-3.5, 3.5]`, Y `[-1.5, 1.5]`다.

현재 1×1 셀 Grid에서 이 직사각형과 **면적이 겹치는** 셀은 X `[-4, 4)`, Y `[-2, 2)`이다. 즉, 빈 공간은 가로 8열·세로 4행이다. 실제 바닥의 맨 위 행은 Y `-3`이며 월드 Y `[-3, -2]`를 차지한다. 트리거 하단 `-1.5`와 타일 윗면 `-2` 사이의 0.5 유닛은 타일 격자로 표현할 수 없는 차이다. 바닥을 트리거와 겹치게 만들지 않기 위해 이 행을 바로 아래 행으로 정의한다.

일반적인 계산은 다음과 같다. 트리거 `bounds.min/max`를 현재 `StageMap.Grid`의 셀 좌표계에서 각 축 `floor(min)`과 `ceil(max)`로 변환해 최대값을 제외한 셀 직사각형으로 만든다. 우주선과 트리거가 이동해도 새 위치를 따르며, 월드 원점에 고정된 수치를 사용하지 않는다. 첫 구현은 기존 생성기와 동일하게 회전하지 않은 1×1 직사각 Grid와 축 정렬된 트리거를 전제로 한다. 트리거가 비활성화되거나 생성 범위 밖에 있으면 설정 오류를 보고한다.

## 3. 생성 셀 판정 순서

1. `PerlinStageGenerator`가 현재처럼 기본·넓은 굴곡·세부 윤곽 노이즈를 합성해 `field ∈ [0,1]`을 만든다. 같은 시드와 설정의 원래 노이즈 값은 바꾸지 않는다.
2. 셀이 귀환 트리거와 겹치는 **필수 빈 공간**에 속하면 타일을 놓지 않는다. 밀도가 1이어도 이 규칙이 우선한다.
3. 셀이 필수 바닥에 속하면 기존 `_terrainTile`을 놓는다. 바닥의 X 범위는 빈 공간과 같고, Y는 빈 공간의 최하단 셀 바로 아래부터 설정한 두께만큼이다. 밀도가 0이어도 이 규칙이 우선한다.
4. 필수 영역 밖의 전환부에서는 원래 노이즈 `field`는 유지하고, 셀에 적용할 임계값만 점진적으로 바꾼다. 전환부 밖에서는 기존 `field < density` 판정으로 돌아간다.
5. 결과 배열을 기존 `StageMap.ApplyGeneratedTiles`에 한 번 전달한다. 개별 타일 파괴 이벤트를 발생시키지 않는다.

빈 공간 전환부는 필수 빈 공간의 위쪽과 좌우에만 적용한다. 바닥 시작 높이보다 아래로 퍼뜨리지 않는다. 바닥 전환부는 필수 바닥의 좌우와 아래쪽에만 적용한다. 따라서 두 전환부가 같은 셀에 서로 반대되는 요구를 주지 않는다. 필수 영역 밖의 모서리 거리는 축별 거리의 합이 아닌 직사각형까지의 유클리드 거리로 계산해 둥글게 물러나는 형태를 만든다.

```text
t = SmoothStep(0, 1, Clamp01(distanceFromRequiredRegion / transitionWidth))

빈 공간 전환부 임계값 = Lerp(0, density, t)
바닥 전환부 임계값     = Lerp(1, density, t)
전환부 밖 임계값       = density
```

암반 판정은 `field < 임계값`이다. 임계값 0은 전부 빈 셀, 1은 전부 암반으로 처리해 기존 밀도 0/1의 뜻을 유지한다. 필수 영역은 이 수식에 의존하지 않고 2·3번의 명시적 규칙으로 보장한다. 전환 폭의 끝에서 기존 노이즈 판정과 정확히 같아진다. 노이즈 분포에 따라 전환부의 모든 셀이 한 줄씩 매끈하게 이어진다고 보장하지는 않으며, 그 모습은 고정 시드로 확인한다.

## 4. Inspector 설정

| 항목 | 의미 | 첫 설정 제안 |
|---|---|---|
| `ReturnArea` 참조 | 보장 영역의 위치·크기를 얻을 씬의 `BoxCollider2D` | 우주선 자식 트리거를 명시적으로 연결 |
| `floorThicknessCells` | 평평한 상단 행 아래로 보장할 암반 두께 | 2셀, 최소 1셀 |
| `airTransitionCells` | 필수 빈 공간 밖에서 원래 노이즈로 돌아가는 거리 | 3셀, 양수 |
| `floorTransitionCells` | 필수 바닥 밖에서 원래 노이즈로 돌아가는 거리 | 3셀, 양수 |

빈 공간의 가로·세로 크기와 바닥의 가로 너비는 트리거가 결정하므로 중복 파라미터로 노출하지 않는다. `floorTopOffset`이나 `spawnOffset`도 이번 단계에 넣지 않는다. 전환부의 별도 경계 노이즈/강도는 우선 도입하지 않는다. 기존 다층 노이즈가 전환부의 모양을 바꾸며, 추가 흔들림은 실제 화면에서 규칙적인 윤곽이 남을 때 검토한다.

## 5. 수정 범위와 구현 순서

1. `Assets/Scripts/Stage/Map/PerlinStageGenerator.cs`: 귀환 트리거 참조와 전환/바닥 두께 설정을 추가한다. `Awake`에서 트리거와 생성 범위의 관계를 검사하고, 현재 셀 반복 중 노이즈 계산 뒤 위 우선순위로 타일을 판정한다. 기존 기준층·추가층의 필드명, 오프셋 생성 순서, `WorldBounds2D`에서 사방 한 셀 확장한 범위는 유지한다.
2. `Assets/Scenes/Stage_a_1.unity`, `Assets/Scenes/Templates/EmptyStageTemplate.unity`: 두 씬의 생성기 컴포넌트에 우주선 자식 `ReturnArea`의 `BoxCollider2D`를 연결하고 제안 전환 폭·바닥 두께를 직렬화한다. 기존 노이즈 설정을 덮어쓰지 않는다.
3. `StageMap.cs`, 우주선 프리팹, `SessionManager.cs`, `WorldBounds2D.cs`, `MiningTileDefinition`은 수정하지 않는다. 적용과 콜라이더 갱신, 플레이어 생성 순서, 채굴 가능성은 기존 흐름을 사용한다.

## 6. 완료 확인 기준

- 정수/비정수 좌표 및 음수 좌표의 트리거를 셀 영역으로 바꿀 때, 트리거와 면적이 겹치는 모든 셀이 비어 있다.
- 필수 바닥의 모든 열이 빈 공간과 동일한 X 셀 범위이고, 첫 행이 빈 공간 바로 아래에 있으며 설정 두께만큼 채워져 있다.
- 밀도 0/1과 서로 다른 고정 시드에서도 필수 빈 공간·바닥이 유지된다. 두 전환 폭 밖에서는 같은 시드의 기존 다층 노이즈 셀 결과가 같다.
- 전환부에서 보장 효과가 바깥으로 갈수록 줄고, 모서리가 축에 맞춘 별도 사각 테두리처럼 보이지 않는지 셀 미리보기/PlayMode 화면으로 확인한다.
- 바닥 타일을 기존 채굴 방식으로 제거할 수 있고, 제거 후 자동 재생성되지 않는다.
- Unity 컴파일, 두 씬의 참조/직렬화, 타일맵 AutoTile·충돌 갱신을 확인한다. 실제 바닥 두께와 전환 폭은 화면 검토 후 조정한다.
