# 다층 노이즈 스테이지 생성기 확장 계획

작성: 2026-09-28. 상태: 기본 다층 합성 구현. 런타임 지형 비교는 미실행.

## 1. 목표와 현재 기준

현재 `PerlinStageGenerator`는 셀마다 펄린 노이즈 하나를 샘플링해 `noise < density`이면 단일 `MiningTileDefinition`을 배치한다. `WorldBounds2D`를 셀로 변환한 뒤 상하좌우로 한 셀씩 더 생성한다. 고정 시드가 아닌 경우 입장마다 새 시드를 쓰며, 생성은 `SessionManager.Awake`보다 먼저 끝난다.

이번 확장은 **큰 형태, 중간 형태, 작은 윤곽을 서로 다른 스케일의 펄린 노이즈로 합성**한다. 기존 셀 범위·타일 적용·시드 선택·생성 시점은 유지한다. 방/통로 굴착, 시작 위치 보정, 연결성 검사, 타일 종류 분포, 생물 배치 정책은 포함하지 않는다.

`Stage_a_1.unity`에는 현재 기본 스케일 X=12, Y=8, 밀도=0.45가 직렬화돼 있다. 템플릿에는 X=12, Y=12, 밀도=0.5가 있다. 이 값을 덮어쓰지 않고 새 노이즈 층의 기본 강도는 0으로 시작한다.

## 2. 합성 방식

기존 노이즈를 **기준층**으로 유지한다. 추가층은 기준층의 값을 기준으로 위아래로 흔든다.

```text
base = Perlin((cellX + 0.5) / baseScaleX + baseOffsetX,
              (cellY + 0.5) / baseScaleY + baseOffsetY)

field = Clamp01(base + Σ [layerAmplitude × (layerNoise - 0.5)])
solid = density == 1 or (density > 0 and field < density)
```

각 추가층의 `layerNoise`도 같은 셀 중심에서 샘플링하되 자기 X/Y 스케일과 시드 오프셋을 사용한다. 노이즈에서 0.5를 빼면 추가층의 평균 기여가 대략 0이므로 `density`를 전체 암반 비율을 조절하는 주 설정으로 계속 쓸 수 있다. 실제 암반 비율이 `density`와 정확히 같아지는 것은 아니다. `Clamp01`은 극단값을 제한하고, 밀도 0/1의 현재 동작을 유지한다.

추가층 강도가 모두 0일 때 **기존 고정 시드의 셀 결과가 같아야 한다**. 이를 위해 기존 `System.Random(seed)`에서 기준층 오프셋 2개를 뽑는 순서를 유지하고, 추가층 오프셋은 넓은 굴곡층·세부 윤곽층 순서로 그 뒤에 생성한다. 두 층은 고정 필드이므로 순서가 바뀌지 않는다. 각 층은 자기 오프셋 쌍을 사용한다.

## 3. 노출할 파라미터

| 구분 | 파라미터 | 지형에서 바뀌는 것 | 첫 구현 권장 |
|---|---|---|---|
| 전체 | `density` | 암반/빈 공간의 임계값. 높일수록 대체로 암반이 많아짐 | 기존 `0..1` 유지 |
| 기준층 | `horizontalScale`, `verticalScale` | 지형 덩어리의 기본 가로/세로 길이 | 현재 씬 값 유지 |
| 추가층 | `enabled` | 해당 층을 비교용으로 켜고 끔 | 켜도 강도 0이면 기존 결과 |
| 추가층 | `horizontalScale`, `verticalScale` | 그 층이 만드는 큰 굴곡 또는 작은 요철의 크기와 방향성 | 양수, 셀 단위 |
| 추가층 | `amplitude` | 그 층이 기준 형태를 얼마나 바꾸는지 | `0..1`, 초기 0; 조정은 작은 값부터 |
| 재현 | `useFixedSeed`, `fixedSeed` | 같은 지형 재현 및 시드 변경 | 현재 필드 유지 |

처음에는 추가층 2개를 제공한다. 예시로 **넓은 굴곡층**은 기준층보다 큰 X/Y 스케일과 강도 약 0.2, **세부 윤곽층**은 작은 X/Y 스케일과 강도 약 0.1부터 비교한다. 이 수치는 권장 탐색 시작점이며, 씬에 자동 적용할 확정값이 아니다. 추가층을 개별 조절할 수 있게 하면 비슷한 길이의 노이즈만 겹쳐 결과가 탁해지는 일을 피할 수 있다.

Inspector에 노출하지 않을 내부 값은 노이즈 중심값 0.5, 셀 중심 샘플 오프셋 0.5, 시드에서 만든 위치 오프셋이다. `octaves`, `lacunarity`, `persistence`를 동시에 노출하지 않는다. 층별 스케일과 강도가 이미 같은 역할을 더 직접적으로 제어한다.

## 5. 변경 위치와 순서

1. `Assets/Scripts/Stage/Map/PerlinStageGenerator.cs`에 직렬화 가능한 추가층 설정(활성, X/Y 스케일, 강도)을 넓은 굴곡층·세부 윤곽층의 고정 필드 두 개로 둔다. 기준층의 기존 필드명은 유지해 씬 값을 보존한다. 노이즈 필드 계산과 타일 배치를 분리해, 최종 `field`를 셀마다 한 번만 임계값 판정한다.
2. 설정을 검사한다. 켜진 층의 X/Y 스케일은 유한 양수, 강도는 유한한 `0..1`이어야 한다. 층 수는 처음에는 기준층 + 추가층 2개로 제한해 Inspector와 비용을 관리한다.
3. 시드로 기준층과 추가층의 오프셋을 생성한다. 고정 시드에서 같은 입력은 같은 셀을 만들고, 추가층 강도 0일 때 기존 단일 노이즈 셀 결과가 보존되도록 한다.
4. `Assets/Scenes/Stage_a_1.unity`, `Assets/Scenes/Templates/EmptyStageTemplate.unity`의 새 직렬화 필드를 확인한다. 기존 X/Y 스케일·밀도·타일 참조는 유지하고 추가층은 강도 0으로 시작한다. `StageMap.cs`, `WorldBounds2D.cs`, `SessionManager.cs`는 이 단계의 변경 대상이 아니다.
5. 고정 시드의 기존/다층 결과를 같은 범위로 나란히 비교해 넓은 층은 큰 윤곽, 세부 층은 가장자리 변화에 기여하는지 확인한다. 밀도·강도를 각각 변경했을 때의 암반 점유율과 생성 시간을 기록한다. `Stage_a_1`의 기존 시작 위치가 비어 있을 필요는 없다.

## 6. 완료 기준과 주의점

- 추가층 강도 0에서 기존 생성 결과가 같다.
- 같은 시드·층 설정·버전에서 셀 결과가 같다.
- 가로/세로 스케일과 강도를 각 층에서 독립적으로 조절할 수 있다.
- 생성 범위는 기존의 `WorldBounds2D` 포함 셀 + 사방 한 셀이고, 같은 단일 Tilemap에 일괄 적용된다.
- 다층 결과를 보고 기본 설정을 선택한다. 합성 후 임계값 분류만으로 열린 공간의 연결이나 플레이어 시작 공간을 보장한다고 간주하지 않는다.

추가층 수는 이번 구현에서 두 개로 고정한다. 결과를 확인한 뒤 층 수가 실제로 더 필요해지면 직렬화 목록으로 확장한다.

## 7. 구현 기록

- 2026-09-28: `PerlinStageGenerator`에 직렬화 가능한 넓은 굴곡층과 세부 윤곽층을 추가했다. 각 층은 활성 여부, 가로·세로 스케일, 강도를 갖는다. 기준층의 오프셋 두 개를 먼저 생성하고 추가층 오프셋을 고정 순서로 생성한다. 최종 노이즈 필드를 한 번 임계값과 비교한다.
- `Stage_a_1`의 기존 기준층 12×8·밀도 0.45, `EmptyStageTemplate`의 12×12·밀도 0.5를 유지하고, 추가층은 각각 24×16 및 4×3 스케일과 강도 0으로 직렬화했다.
- Unity 6000.5.1f1 재컴파일 성공(오류 0). Editor에서 두 씬의 기존 값과 추가층 강도 0을 읽어 확인했다. PlayMode 지형 비교·점유율·성능 측정은 실행하지 않았다.
